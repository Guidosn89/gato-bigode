# Gato Bigode

Joguinho para celular: um gato que reage a toques, come, brinca, dorme e repete o que voce fala com voz fininha.

Abra o `index.html` em um endereco https (GitHub Pages) e permita o microfone no botao Falar.

- Ateliê do Bigode (pintar, 232 desenhos): https://guidosn89.github.io/gato-bigode/pintar/
- Pescaria do Jaci e do Bile: https://guidosn89.github.io/gato-bigode/pescaria/
